# Synthetic server artifacts

These deterministic fictional records, cached embeddings and learned groups allow the Node publishing service to start without Python. They are server inputs, not the downloaded public comparison pack. Express serves only validated aggregate pack files from the private data directory; this artifact folder is outside the browser static tree.

Run `npm run assets:prepare` to reproduce the training experiment, then `npm run release:package` to refresh this snapshot. Fetch the separately pinned encoder with `npm run assets:fetch`. The registry records the exact byte hashes and sizes.

Training status: **baseline**. Labels, sales, prices and attestations are synthetic. The training report retains baseline and held-out failures; no field accuracy or farmer outcome is claimed.
